# 🚀 X4G Gateway v9.2 - Render Deployment Guide

## تنظیم متغیرهای محیطی در Render.com

1. بعد از ساخت پروژه جدید در **Render**:
   - برو به **Settings** → **Environment Variables**
   - این متغیرها رو اضافه کن:

| نام متغیر              | مقدار پیشنهادی                              | توضیح                              |
|-------------------------|---------------------------------------------|------------------------------------|
| `SECRET_KEY`            | هر مقدار تصادفی (مثلاً `x4g-secret-2026`) | برای تولید session                   |
| `ADMIN_PASSWORD`        | `123456` (یا هر رمز دلخواه)                 | رمز ادمین پنل                       |
| `DATA_DIR`              | `/data`                                     | فولدر ذخیره‌سازی دائمی             |
| `RAILWAY_PUBLIC_DOMAIN` | دامنه‌ای که Railway بهت می‌ده (مثلاً `x4g-gateway.up.railway.app`) | برای ساخت لینک‌ها |

**نکته مهم**:  
در Render اول سرویس Web Service رو بساز، بعد متغیرها رو اضافه کن (چون دامنه Public Domain بعد از Deploy می‌ده).

---

## ✅ بعد از Deploy موفق:

1. به آدرس `https://your-domain/dashboard` برو
2. رمز ادمین رو وارد کن
3. لینک پیش‌فرض (بدون محدودیت) رو کپی کن
4. در v2rayNG / NekoBox / Streisand وارد کن
5. برای ساخت گروه ساب + محدودیت ترافیک، از بخش **مدیریت لینک‌ها** و **گروه‌ها** استفاده کن
